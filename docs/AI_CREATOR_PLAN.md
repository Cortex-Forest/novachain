
# AI 创作者（链上数字生命体）规划与阶段 0 PoC

> 状态：阶段 0 PoC 已落地（见 `scripts/ai_creator_demo.py` 与 `test_ai_creator.py`）

## 一、目标

在 Nova 链上实现「自主 AI 创作者」：一个拥有自己地址、钱包与链上规则合约的数字生命体，
能自主创作内容、发布售卖、自动分配收益，并逐步支持与其他 AI 协作。

## 二、可行性结论

Nova 链现有基础设施已覆盖约 70%：

| 能力 | 现状 | 缺口 |
|------|------|------|
| 地址/钱包/签名 | QuantumWallet（Dilithium5/Ed25519）、签名交易 | 无 |
| 链上规则 | NexLang 合约 VM（部署/调用/状态） | 需扩展外部调用与定时器（远期） |
| 自主创作与售卖 | `nova:text:create/buy`（90/10 自动分账）、粉丝代币、策展 | 无 |
| 内容上链 | 存储网络 pin（CID） | 无 |
| 算力生成 | 算力任务市场（AIGC 生成/推理） | 接入 Agent（远期） |
| **AI 身份与约束** | 无 | **阶段 0：身份注册 + 日预算硬约束** |
| **Agent 运行时** | 无 | 阶段 2：调度器/决策循环/内容引擎/签名服务 |

## 三、总体架构

```
链上（Nova）                         链外（Agent Runtime，阶段 2）
┌──────────────────────────┐        ┌──────────────────────────┐
│ AI 身份注册（nova:ai:*)  │ 事件流  │ 感知器：扫描链上事件/需求  │
│ 日预算硬约束（链上强制）  │ <─────  │ 决策循环：选题→调模型→生成 │
│ 文本合约 90/10 自动分账   │ 签名交易 │ 执行器：签名发布/购买/分账 │
│ 粉丝代币/策展/声誉/算力    │ ──────> │ 安全护栏：预算/白名单/暂停 │
└──────────────────────────┘        └──────────────────────────┘
```

阶段 0 只做「链上身份 + 预算约束 + 自动发布售卖」的最小闭环，Agent 运行时用演示脚本模拟。

## 四、阶段 0 PoC（已实现）

新增链上操作（与 SocialFi 一致：sender==receiver、data 为 JSON、签名交易确定性上链）：

- `nova:ai:register`：注册 AI 创作者身份 `{name, owner, daily_budget, meta, status}`，
  一个地址唯一身份；预算范围 0.1–10000 NOVA/日。
- `nova:ai:config`：仅 owner 钱包可操作（data 携带 `target` 指明 AI 地址）：`pause` / `resume` / 调整 `daily_budget`。

预算约束在节点交易流水线强制执行（不是链外建议）：
- `validate_tx`：AI 地址发起任意交易时，`当日已支出 + 本次金额 <= 日预算` 才放行；
  状态为 `paused` 时全部拒绝。
- `apply_tx`：按 UTC 日期窗口累计当日支出，跨天自动重置。

收益闭环复用现有文本合约：购买自动 90% 归 AI 钱包、10% 归生态基金。

## 五、分阶段路线图

| 阶段 | 内容 | 状态 |
|------|------|------|
| 0 | 身份注册 + 日预算硬约束 + 自动发布/分账 PoC | ✅ 已实现 |
| 1 | 链上核心完善：状态机扩展、事件订阅 RPC、前端联动 | 待启动 |
| 2 | Agent 运行时：调度器/决策循环/内容引擎/签名服务/审计日志 | 待启动 |
| 3 | AI 协作：联合创作分账、AI 互持粉丝代币、算力委托 | 待启动 |
| 4 | 自治与治理：社区冻结/清算、MPC 多签、模型 Key 托管 | 远期 |

## 六、关键设计决策

1. **私钥归属**：阶段 0/1 由运营方托管 + 链上硬约束（日预算、状态冻结在链上强制）；
   远期演进 HSM/MPC 多签。私钥泄露也花不出超预算金额。
2. **自主度分级**：L1（预算内自动创作售卖）→ L2（自动再投资/合作）→ L3（治理接管）。
3. **内容可信**：内容哈希上链（`nova:text:create` 已支持 CID），远期接入算力市场双节点验证。
4. **收益模型**：沿用 90/10 自动分账；AI 钱包收入可再投资。

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| 私钥泄露 | 链上日预算硬约束 + 状态冻结 + 远期 MPC |
| AI 失控/刷奖励 | 预算上限、owner 暂停、防刷规则（同 sender/合约每日一次） |
| 内容合规 | 发布前审核层、人类创建者署名、免责条款 |
| 法律主体 | 链上资产法律上归运营方/创建者，条款明示 |
